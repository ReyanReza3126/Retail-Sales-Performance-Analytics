About the Project

This project analyses global retail sales data from 2011 to 2014. The main objective is to identify sales trends, profitable product categories, customer behaviour and regional performance.

Tools Used: Python, Pandas, Matplotlib, Seaborn, MySQL and Jupyter Notebook.
